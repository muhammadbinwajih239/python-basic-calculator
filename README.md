# 🧮 Python Basic Calculator

A simple command-line calculator built with Python as part of my journey in Python programming and AI & Data Science.

## 📌 About the Project

This project performs basic mathematical calculations based on the operator selected by the user. It is designed to practise Python fundamentals, including user input, numeric conversion, conditional statements, and arithmetic operators.

## ✨ Features

- Addition (`+`)
- Subtraction (`-`)
- Multiplication (`*`)
- Division (`/`)
- Exponentiation (`**`)
- Modulo (`%`)
- Division-by-zero handling
- Invalid-operation message

## 🛠️ Technologies

- Python 3
- `input()` and `float()`
- `if`, `elif`, and `else`
- Arithmetic and comparison operators

## ▶️ How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

   `python calculator.py`

   If your system uses the `python3` command, run `python3 calculator.py` instead.

5. Enter two numbers and select an operation when prompted.
